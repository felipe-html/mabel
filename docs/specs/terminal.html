Novo terminal do Mabel

Protótipos para refinar o terminal antes de implementar: a tela inicial com os comandos e o painel da fila. Os dados são de exemplo.

Situação

Clique no terminal e use ↑ ↓ e enter. Digitar filtra a lista; esc limpa ou volta. Nos formulários: enter edita, ←→ trocam opções, espaço marca.



    

      

        
Decisões

        
    
          
  1. Tela inicial aprovada.
            Nome, projeto e o que espera por você; lista navegável com filtro; o nome do shell à direita; a ordem acompanha o momento; sem desenho por enquanto.
    2. 
          
  2. Os nomes mudam no shell também.
            Um verbo por comando, igual ao do título, sem apelidos para os antigos. A doc de integração registra a troca.
    3. 
          
  3. Menos comandos no menu.
            O saldo entra em "Conferir o estado"; a lista das prontas entra em "Entregar uma unidade".
    4. 
          
  4. Sem Mabel no diretório.
            Aparecem Começar, Listar e Auditar projetos, e Pedir algo avulso.
    5. 
        

      

      

        
Telas dos comandos: para refinar

        
    
          
  1. Quatro tipos de tela. Formulário (um campo por opção), escolha de item (só os itens no estado certo), vista (só leitura) e fluxo (Decidir, Rodar).
            Sugestão: manter só esses quatro, para todo comando novo caber num deles.
    2. 
          
  2. A linha $ mabel … embaixo do formulário.
            Sugestão: manter. Ensina o comando de shell equivalente e deixa copiar para um script.
    3. 
          
  3. Aprovar e Responder no menu. "Decidir as pendências" já passa pelos dois, uma decisão por vez.
            Sugestão: tirar os dois do menu e deixá-los só no shell.
    4. 
          
  4. Ações que apagam ou revertem. Cancelar, rejeitar e remover projeto aparecem com o botão em vermelho.
            Sugestão: o botão vermelho basta para cancelar e rejeitar. Remover projeto pede o nome digitado, como o --confirmar de hoje.
    5. 
          
  5. O que fica depois do resultado. Hoje, enter volta ao menu e o resultado some.
            Sugestão: ao voltar, o resultado é impresso no terminal comum, acima do menu, para ficar na rolagem.
    6. 
          
  6. Rodar a fila sai do menu. O painel da aba Fila toma a tela.
            Sugestão: quando a fila termina ou você solta com ctrl+c, a tela volta ao menu com o resumo.
    7.

Decisões

      
    
        
  1. Frase padronizada, montada pelo Mabel a partir das ferramentas.
          Não usa o texto do agente. A causa de uma nova tentativa aparece no ↻. A chave "Frase padronizada" no topo continua só para comparar.
    2. 
        
  2. Gates em linhas próprias enquanto o item roda.
          Ao concluir, o item vira uma linha só.
    3. 
        
  3. Os três últimos concluídos ficam na tela.
          Os anteriores viram "+N concluídos". "Mostrar concluídos", na barra de ações, abre as etapas desses três.
    4. 
        
  4. Painel só no TTY.
          Fora dele (CI, pipe, --json), a saída de hoje sem mudança. O detalhe continua no banco e no transcript (G1).
    5. 
        
  5. Planejamento em lote com fase no cabeçalho.
          No planejamento, cada item mostra planejar e o critério de início (G2). Na execução, o plano aceito vira ✓ planejar.
    6. 
        
  6. Terminal baixo recolhe por ordem.
          Ferramentas abertas, depois pendentes ("+N na fila"), depois concluídos. O item ativo e o rodapé nunca são cortados; abaixo do mínimo, volta o log de hoje. Este ponto não está simulado aqui.
